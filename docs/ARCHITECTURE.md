# 工程架构

Android 是实际查询客户端。`UsageViewModel` 管理页面、校区、日期和数据状态，`SchoolRepository` 协调远端请求、认证与 Room 缓存。`WaxyClient` 查询网安基地电费和能源费，`NetworkClient` 读取学校校园网套餐页，`MainCampusPortal` 约束主校区官方页面允许访问的地址。

水电能源登录取得会话后，缓存按账户与绑定信息的哈希范围隔离。查询遇到认证失效时，已选择记住登录的账户最多重新认证一次；再次失败或需要验证码时交还用户操作。学校官方会话到期无法由客户端无限延长。`SessionVault` 使用 Android Keystore 管理加密密钥，保存的数据不进入设计配置。

统计记录保留日期、类型、数值、来源与拉取时间。有效零用量与缺失统计分开表示；次日 08:00 是预期发布时间提示，不能据此生成不存在的统计。更新失败时允许保留之前的数据，并展示对应状态。切换主校区后使用独立官方页面，不把网安基地记录作为主校区数据展示。

路线模块位于 `feature/routes`，分为数据访问、模型、时间评估和界面。城市通提供地点和路线查询；定位在设备前台主动获取，坐标按明确的坐标系转换。路线时间计算优先使用提供方总耗时，不重复累加假定等候时间。武汉地铁公开首末班资料和线网属于独立参考数据，不代表实时列车位置或完整换乘班次。

默认页面使用 Compose 绘制。`DesignConfig` 读取打包的 `design/project.json`，调试版可以读取通过 ADB 写入的同名私有配置。`AppearanceStore` 保存用户从设备选择的图片。首页、趋势、个人页和背景分别可替换，趋势图像保持完整比例。

电脑设计工作台使用 React 与 Vite，读取同一份设计结构。`DesignStore` 校验结构、采用修订号避免陈旧页面覆盖新内容，并原子写入配置。开发服务器仅绑定回环地址，设计写入接口限制来源与请求体大小。所有账单和余额使用虚构演示数据，工作台不导入手机会话。

公开版保留日常登录、查询、缓存与主题功能，移除了只用于本地调研的一次性会话导入与真实账户验证脚本。首次构建后，由使用者在自己的设备完成官方认证。
