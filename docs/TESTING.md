# 验证说明

`npm test` 验证设计结构、原子保存、修订冲突、统计预期发布时间和零值/缺失的语义。测试在临时目录操作，不覆盖设计工作台的配置。

`npm run build` 对工作台执行 TypeScript 检查和 Vite 构建。`npm run test:ui` 使用隔离的测试设计目录，验证编辑保存、路线页面、人物主题、完整趋势图片、本地换图及校区切换。Playwright 默认使用它管理的 Chromium；也可通过 `CAMPUS_CHROME_PATH` 使用已安装的浏览器。测试截图属于生成物，不提交。

在 `android/` 执行 `gradlew :app:testDebugUnitTest`，通过虚构账户、MockWebServer 和合成路线响应验证统计解析、一次认证恢复、Cookie 隔离、路线耗时、数据缺失、缓存以及官方页面的地址约束。地铁参考资料使用公开来源；不进行真实个人账单断言。

执行 `gradlew :app:assembleDebug` 验证 Android 调试包可构建。构建成功不等于已验证所有品牌手机兼容性、真实服务长期可用性或官方认证的长期有效性。正式 Release 构建仍被限制。

在自己的设备上体验时，应分别检查首次登录、重启后会话、主动更新、验证码处理、网络失败的缓存显示、两校区切换、图片恢复默认及定位权限拒绝后的手动输入。真实数据和截图应保留在本地，不加入公开仓库。

发布前运行 `python scripts/audit_release.py`。脚本检查 Git 文件清单；未建立 Git 时检查源码目录并排除明确的生成目录。它拒绝常见私密文件类型、机器绝对路径、常见真实密钥格式和个人联系方式。图片本体及第三方许可还需按资源说明审阅。
