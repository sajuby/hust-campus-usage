# 公开源码脱敏记录

整理日期：2026-10-25。本目录是从工作工程按源码白名单建立的独立副本，原工作工程与设备登录状态未改动。此记录说明仓库文件处理范围，不包含任何个人信息清单或真实查询结果。

## 文件处理

保留 Android 与工作台源码、设计配置、必要的默认美术资源、Gradle Wrapper、锁文件、公开地铁参考资料以及自动化测试。文档重新编写，移除了本机路径、调研过程与真实账户验收记录。

不纳入浏览器配置、微信或企业微信调研资料、账户文件、会话、房间绑定、账单快照、数据库、定位历史、个人导入图片、截图、HAR、日志、工具链、本机环境配置、设备备份、签名文件、APK 和其他构建产物。依赖与测试生成目录在验证结束后移至源码副本之外保存。

上述范围针对源码目录与 Git 历史。供直接安装的 APK 从脱敏源码单独构建、检查并发布至 GitHub Releases 附件，不进入 Git 历史。当前开发预览版为 `v0.5.0-preview.1`，应用内版本为 `0.5.0-dev`。

公开版不包含原工作目录的 Git 历史，使用全新的 Git 仓库和中性的项目提交身份；初次提交只包含审阅后的公开源码。

## 数据与资源处理

用电日序列、校园网余额和流量等演示值替换为虚构数据。学校认证测试只使用明确标记的虚构凭据与 MockWebServer；路线解析测试使用重新构造的合成响应，删除原始查询响应中的坐标和附加字段。官方地铁资料测试通过独立的公共地点样例验证，不依赖该原始响应。

仅用于私有调研的一次性浏览器会话导入、真实账单验收脚本和相应 Activity 调试入口未纳入公开版。正常的官方登录、认证恢复、数据查询和设计同步功能仍保留。

检查了工作台与 Android 共 13 个默认位图文件，未发现需移除的 EXIF、PNG 文本或常见注释元数据；所有图像解码后的尺寸与像素和原默认资源一致。趋势配图完整保留，不重绘、不裁切。用户设备后来上传的图片不属于默认资源，未纳入本副本。保留必要第三方许可和公开数据出处。
