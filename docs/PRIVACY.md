# 隐私与本地数据

公开源码不提供任何可用的个人账户、密码、Token、Cookie、房间绑定或定位历史。测试中的账号和会话字面量使用 `test-`、`demo-` 等明确的虚构值。演示账单不是实际查询记录。

真实使用时，水电能源凭据和校园网 Cookie 保存在 Android 应用私有目录，通过 Android Keystore 加密。选择保持登录会保存恢复认证所需的信息；需要验证码或官方会话失效后无法恢复时，仍需用户重新完成认证。应用禁止系统备份。设备卸载、清除应用存储会清除这些本地数据。

用量查询结果通过 Room 保存在本地。账户与绑定范围用于隔离数据，不随设计同步导出。路线查询会把所选起终点发送至相应出行服务；定位只在使用相关功能并授权后获取。当前工程没有自建收集账户与定位的服务端。

从设备替换的主题图片保存在应用私有存储。电脑预览中选择的图片保存在当前浏览器的本地存储，与手机数据相互独立。恢复默认图片可撤销自定义显示；清除应用或浏览器对应站点数据可以清除本地存储。

开发时不要提交设备备份、账单导出、日志、截图、HAR、数据库、会话文件、浏览器配置或签名文件。`.gitignore` 用于减少误提交；发布前还应运行 `python scripts/audit_release.py` 并检查 Git 暂存内容。该检查提供规则检测，不能代替对新增文档、图片及二进制资源的人工审阅。
