# 默认界面资源

此目录仅包含应用默认界面所需的插画与横幅，不含设备图库导入的个人照片、聊天截图、登录截图或调研截屏。

`character-home.png`、`character-profile.png` 及三张 `route-*.png` 为项目设计阶段生成的界面插画。`character-trends-original.jpg` 为项目提供的水面人物参考插画，以原比例完整嵌入趋势页，不裁切或重绘。`campus-banner.svg` 为可编辑横幅，Android 版本使用其栅格化资源。

这些默认资源用于展示本项目设计，不授予第三方人物形象或参考作品的额外授权。它们不沿用第三方坐标转换代码的 MIT 许可。替换或再分发资源时，请依据对应素材的授权范围处理；使用者也可在应用内选择自己的图片。

公开源码整理时已检查图片的 EXIF、PNG 文本块和其他常见注释元数据。必要时仅移除元数据，不改变解码像素。Android 资源与工作台资源保持一致。
